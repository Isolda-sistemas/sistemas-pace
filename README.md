# Sistema PACE - Gestão de Projeto Social

Protótipo funcional desenvolvido para a disciplina de Projeto Integrador II do curso de Tecnologia em Sistemas para Internet (UESPI).

## 🚀 Funcionalidades Implementadas
- **Tela de Login:** Autenticação de usuários para acesso restrito.
- **Dashboard / Tela Inicial:** Painel geral de controle do sistema.
- **Menu de Navegação:** Acesso rápido entre módulos.
- **Cadastro de Participante:** Formulário com validações para registro de novos participantes.
- **Relatórios:** Visualização resumida dos dados cadastrados.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript
